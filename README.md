# Controls 
Press F1 to toggle GUI
To start the macro press F1 and to exit the macro press ESC
# Settings

Display settings (PC)
100% scale
QWERTY Keyboard
Decent PC specs (otherwise you will lag too much or crash)
Make sure your taskbar isn't too high otherwise it won't click all the buttons.



Display settings (Ingame/Roblox)
0.52 Camera Sensitivity 
Normal/Default Camera Mode
Roblox must be WINDOWED
Don't use any fonts that change how letters look (like minecraft font for example)
Only use the english version of roblox. No translations
Don't use bloxstrap as it will break the macro.
Turn off roblox performance tab
